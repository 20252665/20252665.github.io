Based on the Moodle **Template 2 (MyResume)**. The site includes updated Home, About, Skills, and Resume content; a new AI-themed Home illustration and About illustration stored in `assets/img`; document language (`en`), UTF-8, author, description, browser title `My CV`, and a new favicon.

## View locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR-EXACT-USERNAME.github.io` (replace the placeholder with your GitHub username).
2. Upload **all the contents** of this folder, including `index.html` and `assets`, at the repository root. Do **not** upload the outer containing folder alone.
3. Under repository Settings → Pages, select Deploy from a branch, main, and `/ (root)`, then save if not already configured.
4. Visit `https://YOUR-EXACT-USERNAME.github.io/` and verify the site.

## Defence talking points
- `<!DOCTYPE html>` says HTML5; `<html lang="en">` defines the page language.
- `<head>` has metadata, title and stylesheet links; `<body>` contains visible content.
- `<meta charset="utf-8">` enables Unicode characters. The description and author meta tags describe the page.
- The favicon appears in the browser tab.
- `<section id="hero">` is the Home section; `<section id="about">` is About.
- Images are in `assets/img/`, displayed with `<img src="..." alt="...">`.
- CSS sets the visual design; JavaScript provides visual interactions; Live Server previews changes locally; Prettier formats code.
- GitHub Pages serves a static website publicly from repository files.

**Privacy:** No personal phone number or email address is published. Template attribution is retained.
